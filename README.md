# Forecasting U.S. Recessions with Machine Learning

This project asks a simple question: can past economic data tell us whether the U.S. economy is in, or heading into, a recession? I built a **binary classification** model, meaning each month is labeled either "recession" (1) or "no recession" (0), and trained several machine learning models to learn the difference from historical patterns. The work was completed as a final project for ECON 425: Machine Learning at UCLA.

**Dataset.** All data comes from the Federal Reserve Economic Data (FRED) database, pulled directly through the `fredapi` Python library. It covers monthly observations from February 1982 to October 2024 and includes real GDP, unemployment, inflation (CPI), consumer sentiment (University of Michigan index), the yield curve (10-year minus 3-month Treasury spread), M2 money supply, industrial production, and the 3-month Treasury rate. The target variable is FRED's official recession indicator (USRECD). Because the series are reported at different frequencies, I resampled everything to monthly, filled quarterly GDP forward so each month carries the latest known value, and dropped variables with long gaps (lending standards and corporate bond spreads) rather than inventing a decade of missing data.

**Methodology.** Economic signals often show up with a delay, so I used **feature engineering** to create **lagged variables**: the value of each indicator 1, 3, and 6 months earlier. I also added **rolling sums** that count how many of the last 3 and 6 months were in recession. To mimic real forecasting, I used a **time-based train/test split** instead of a random one: the models learned from 1982 to 2015 and were tested on 2016 to 2024, data they had never seen. I compared four models: **Logistic Regression** (a simple, interpretable baseline with standardized features), a **Decision Tree** with balanced class weights, **Random Forest** (many decision trees voting together), and **XGBoost** (trees built sequentially, each correcting the last one's mistakes). Models were evaluated using **accuracy, precision, recall, F1-score, confusion matrices, 5-fold cross-validation, and ROC-AUC curves**.

**Key findings.** Random Forest and XGBoost performed best, each reaching 98% test accuracy and catching both recession months in the test period (the 2020 COVID downturn) with no missed recessions, though they also raised two false alarms. XGBoost had the highest and most stable cross-validation accuracy (99.3%, ±1.0%). **Feature importance** analysis showed that recent recession history, consumer confidence, and the yield curve were the strongest predictors, consistent with the economic view that an inverted yield curve signals a coming downturn. Logistic Regression lagged well behind (84% accuracy), suggesting the relationships in the data are not simply linear.

**Limitations.** The biggest challenge is **class imbalance**: recessions are rare, so the test set contains only 2 recession months out of 105. This makes accuracy misleading, since a model that always predicts "no recession" would still score about 98%. The 2025 to 2026 forecast is also limited because future inputs were held constant at their recent 6-month averages, which produced a flat Random Forest recession probability of roughly 33%. Tree-based models also struggle to extrapolate beyond conditions seen in training.

**Tools:** Python, pandas, NumPy, scikit-learn, XGBoost, statsmodels, matplotlib, seaborn, fredapi
